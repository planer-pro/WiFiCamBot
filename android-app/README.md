# WiFiCamBot — Android-пульт

Flutter-приложение для управления роботом WiFiCamBot: лайв-видео и моторы на
одном экране (без скролла), настройки — в меню. Вход по паролю (стандартный
`1234`, меняется в настройках; хранится хэшем в SharedPreferences).

## Возможности

- **Видео** — MJPEG с порта 81, поворот кадра как на веб-странице робота,
  автопереподключение через 1 с при обрыве.
- **Управление** (виды — как у робота, читаются из его настроек):
  - *Кнопки* — крестовина, удержание = движение, отпускание = стоп;
  - *Джойстик* — экранный круг: отклонение задаёт направление и мощность;
  - *Геймпад* — Bluetooth-геймпад, подключённый к телефону (левый стик);
    для Android это устройство ввода, разрешений не нужно.
- Повтор команды каждые 500 мс при удержании (страховка от сторожевого
  таймера робота 1.5 с); стоп после отпускания дублируется ещё дважды
  (интервал 400 мс) — как в веб-интерфейсе.
- **Настройки робота** — качество, поворот кадра, свет+цвет, вид управления,
  мощности (своя пара у кнопок, общая у аналоговых видов), разгоны, точка
  страгивания. Читаются с робота (`GET /status`), изменения уходят сразу
  (`/set`).
- **Подключение** — адрес робота (IP в локальной сети или внешний адрес/
  туннель) и порт стрима (81). `wificambot.local` на Android обычно не
  резолвится — вводите IP, например `http://192.168.1.137`.
- **Доступ извне локальной сети** — через облако Keenetic (KeenDNS):
  адрес робота `https://robot.myhome3.netcraze.link`, полный URL стрима
  `https://stream.myhome3.netcraze.link` (стрим у робота на отдельном
  порту, поэтому в облаке публикуются два поддомена). Дома те же поля
  можно оставить пустыми/локальными — работает и так, и так.

## Сборка

Требуются Flutter SDK и Android SDK (platform 36):

```bash
cd android-app
flutter pub get
flutter build apk --release
# готовый файл:
# build/app/outputs/flutter-apk/app-release.apk
```

Установка на телефон (отладка по USB): `adb install -r build/app/outputs/flutter-apk/app-release.apk`

APK подписан отладочным ключом (для личной установки достаточно; обновления
ставятся поверх тем же ключом с этой машины).
